# Contributing

Thank you for helping improve this technical documentation project.

## How to contribute

1. Review the existing documentation structure before adding new files.
2. Keep titles clear and descriptive.
3. Use Markdown consistently and include headings where useful.
4. Add related documents to the index when relevant.
5. Preserve source notes and historical records unless they are clearly obsolete.

## Suggested content standards

- Use short, direct headings
- Keep content factual and source-aware
- Separate implementation notes from final design decisions
- Mention commands, dependencies, and configuration when relevant
- Include date or version context if the document may change over time

## Pull request guidance

- Keep changes focused
- Update the main documentation when adding new sections or topics
- Ensure the repository remains easy to search and navigate

## Documentation style

This project mixes English and Arabic materials. Please keep terminology consistent and avoid unnecessary formatting that reduces readability.
